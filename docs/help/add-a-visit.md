1. Open the job. Admin and sales: select Delivery, then the [Commissioning] row, and look at Visits. Engineers see Visits on their job page.
2. Admin and sales select [Add visit], pick the type and the day, and optionally the engineer and a note. Select [Save].
3. When a visit is finished, select [Mark visit done] on it. The order is done when every visit is done.
4. Select [Service report] on a visit to download a PDF with a line each for the customer and the engineer to sign.

Note: An engineer can change only the visits that are theirs. The report has no prices.
