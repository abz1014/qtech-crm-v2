1. Every message is prepared for the channel used last. Select [Email instead] or [WhatsApp instead] to switch (on an RFQ, under [Show the whole message]).
2. The app remembers the choice on this device.
3. Select [Open in WhatsApp] or [Open in email]. The message is already filled in.
4. Press Send there, then select the Mark button in the app so that it is recorded.

Tip: If no mobile number is saved, copy the message instead. The app never sends anything on its own and keeps no copy of the message.
