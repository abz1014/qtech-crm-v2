1. Select [Money], then [Expenses]. In [Quick add] enter the amount.
2. Select [Other]. Alternatively, enter a description and select the Other offered under it.
3. Enter [What was it for?], for example "Courier from shop to office". It cannot be left empty.
4. Select [Save]. The expense report lists each Other by the text entered.
5. When one title is used 3 times, a banner offers to make it a category. Select [Make it a category].

Note: Other keeps the category list short. Each group has its own Other, chosen from the text entered.
