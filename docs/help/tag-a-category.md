1. On an RFQ, select the category chip under an item. A dashed chip is only a guess: select it and choose the category to save it.
2. On the page of a supplier, find [Categories they deal in]. Select [Tag] on a category the supplier carries, or [Untag] to remove it.
3. To tag a category that is not listed, use [Tag a category] under the list.

Tip: A supplier that prices an item in a category is added to it automatically. Tagged suppliers are listed under "Deals in" when asking for prices.
