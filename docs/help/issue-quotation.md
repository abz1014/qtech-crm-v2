1. On the RFQ, select the green [Issue quotation].
2. Check [Unit price, net PKR] for each item. Select a suggested price or type one.
3. Check [Valid until], [Delivery] and [Payment terms].
4. Select [Preview PDF] if you want to see it first.
5. Select [Issue quotation], then [Share] or [Download PDF], and send it to the customer.

Safe to try: [Preview PDF] saves nothing, and an issued quotation stays on record. To change it later, use [Revise quotation].
