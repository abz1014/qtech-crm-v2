title: Reset someone's password
roles: admin
keywords: password, forgot, reset, login, sign in, locked out
screens: /settings
---
1. Select the avatar at the top, then [Team].
2. Find the person and open the menu of that person.
3. Select [Reset password]. The new password is shown once. Give it to the person directly.

Tip: Your own password is under [Change password] in the avatar menu.
