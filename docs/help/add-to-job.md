1. Open the job. Copy the supplier's WhatsApp message, then paste it anywhere on the page. It lands in [Add to this job].
2. Check the supplier it names under [From which supplier?]. Change it if it is wrong.
3. Look at the prices it read. Anything marked Check this is worth a second look. Untick one to leave it out.
4. Tap [Accept N prices]. The prices go on that supplier's row.
5. The customer answering a question instead? It says [Customer answer]. Tap [Save answer].

Tip: Wrong guess? Tap [Supplier price], [Customer answer], [Site photo] or [Note] above the button.
