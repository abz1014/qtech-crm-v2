1. Open the job. Copy the supplier's WhatsApp message, then paste it anywhere on the page. It lands in [Add to this job].
2. Check the supplier it names under [Supplier]. Change it if it is wrong.
3. Look at the prices it read. Anything marked Check this is worth a second look. Untick one to leave it out.
4. Select [Accept N prices]. The prices go on that supplier's row.
5. If the reply is the customer's answer to a question, it says [Customer answer]. Select [Save answer].

Note: If the type is wrong, select [Supplier price], [Customer answer], [Site photo] or [Note] above the button.
