1. Select [Money], then [Lock a month]. Today lists a reminder in the first 10 days of the month.
2. Only the checks with something to look at are listed. Select one to fix it.
3. None of them blocks locking. Select [Lock <month>], then confirm. Each lock covers one month only.
4. Months lock one at a time, oldest first, and only while that month is on screen.
5. If an older month is still open, the green button says Go to that month. It only moves you there and locks nothing. Then select [Lock <month>].
6. To reopen a month locked by mistake, select [Reopen] under [Locked months]. It is logged.
7. Only the latest locked month has [Reopen]. To reopen an earlier month, reopen the newer ones first, newest first.

Note: Locking freezes payments, expenses and invoices dated in that month.
