roles: admin

related: something-wrong
---
1. Open the order and tap [More], then [Delete order]. Only an admin sees it.
2. If it says what is in the way, such as an invoice, do that first. A payment or an issued PO means [Cancel order] instead.
3. Read what goes with it, then tap [Delete]. This cannot be undone.

Tip: To drop one line only, tap [Edit GST and lines], then [Remove line]. The last line stays.
