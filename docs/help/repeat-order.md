1. Tap [New], then [Order without enquiry]. [Repeat a past order] opens.
2. Under [Find a past order], search by company, site, item or order number.
3. Pick the closest one. Add the [Customer PO number] if you have it.
4. Tap [Create order]. Nothing is ordered from the suppliers yet.
5. On a done order's page, [Repeat order] opens this with that order already picked.
