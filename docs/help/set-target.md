1. Tap your avatar at the top, then [Settings], then [Targets].
2. Tap the person's box under the quarter, type the amount and press Enter.
3. Last quarter's targets carry over in one tap: [Copy last quarter]. It only fills empty boxes.
4. For quarters already over, tap [Show earlier quarters].

Tip: Each person sees only their own target, on Today.
