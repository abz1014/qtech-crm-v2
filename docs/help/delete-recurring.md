1. Select [Money], then [Expenses]. Find the item under [Recurring] and select its name.
2. Select [Delete recurring expense]. It says how many expenses were recorded from it.
3. Select [Delete]. It is no longer due each month. It cannot be undone.

Note: Expenses already recorded from it stay as they are, even in a locked month. To pause it instead, untick [Active (due each month)] and select [Save].
