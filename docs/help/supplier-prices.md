1. Open the RFQ. In [Suppliers asked], select [Enter reply] beside the supplier.
2. Select [Paste reply], paste what the supplier sent, then select [Read it]. For a supplier's PDF or a screenshot of one, select [Read a PDF or photo].
3. Check the price, currency and lead time it read.
4. Select [Accept N prices].
5. Or type each price in its box and select [Save reply].
6. If the supplier has no price, select [Cannot quote] and pick the reason.
7. If they priced some items and will send the rest later, select [The rest: quoting later (N)]. A pasted "please wait" is read the same way.

Tip: Each price needs a lead time. The weight of one unit is optional. Suppliers are listed by name: the CRM never marks or suggests one. To see every supplier's price side by side, select [Download Excel] on the job page. Its first sheet has one row per item and a column for each supplier.

Safe to try: nothing is saved until you accept or save.
