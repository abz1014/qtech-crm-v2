1. Select [Money], then [Expenses]. The [Cash in hand] line shows what should be in the office cash.
2. The first time, select [Set opening cash] and enter the cash counted.
3. For cash taken out of the bank for the office, select [Cash drawn] and enter the amount. It is not an expense.
4. To check, count the cash, select [Count cash], enter the amount and select [Save count].
5. If the count is short or over, the difference is saved with the count. Check for an unrecorded cash expense.

Note: Every cash expense lowers the expected cash. The same line is on Lock a month.
