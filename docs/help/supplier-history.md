1. Select [Companies], then [Suppliers], and open the supplier.
2. The line under the name counts replies, orders and late deliveries. Select (i) to see how they are counted.
3. [RFQs] lists each item the supplier was asked about, with the price, reply time and outcome. Select [Show all N] for older entries.
4. Sites, brands and details are under [More about this supplier].
