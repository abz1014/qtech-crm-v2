1. Open the RFQ. Once a quotation is out, the button reads [Revise quotation]. Select it.
2. Change the prices or terms.
3. Select [Issue revised quotation].
4. Select [Share] or [Download PDF], and send it to the customer.

Tip: The first quotation stays exactly as it was. The revised one keeps the same number.
