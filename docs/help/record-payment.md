1. Select [Money]. It opens on [To collect].
2. Find the order and select [Record payment]. On a phone, the button is on its card.
3. [Amount received, PKR] starts at the balance due. Change it for a part payment.
4. Check [Date received] and [Paid via], then select [Save payment].

Tip: The balance is gross, GST included. For an advance before the invoice, open the order, select [More], then [Record payment].
