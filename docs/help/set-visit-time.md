1. Open the order. Engineers tap [Visit time and type]. Admin and sales tap [Edit] under Commissioning.
2. Choose the type: Installation, Survey or Service. Add the time if you know it. The time is optional.
3. Tap [Save].

Tip: your list shows the day's sites like "10:00 · Install · customer · site". An engineer can set this only on a site assigned to them.
