1. Tap [Money], then [Expenses], then [Add expenses].
2. Type the amount, then the category. Two or three letters find it.
3. Enter adds a row. Tab moves along the row.
4. Tap [Save N expenses], or press Ctrl+Enter. All rows save together.

Tip: On a phone each expense is a card, and the camera button adds the receipt photo.
