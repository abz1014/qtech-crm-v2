1. Select [Money], then [Invoices].
2. Tick the invoices the courier took, then select [Invoice posted today].
3. For GST paid to FBR, tick the invoices, select [Add PSID], paste the PSID once, then select [Deposited today].
4. For the FBR receipt, open the invoice and select [Add receipt]. A filed invoice opens as a summary. Select [Edit] to change it.

Tip: [Needs attention] shows what is late.

Safe to try: If invoices were stamped by mistake, select [Undo] on the message at the bottom.
