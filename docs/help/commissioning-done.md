1. Open the order. Once the job is due, the green button is [Mark done today]. Engineers: on your job's [On site] card the button is [Installed today].
2. Select it when the job is finished. One select.
3. If no date is set, admin and sales see the green button [Plan commissioning]. Set the date and the engineers there.
4. Site notes: in the Delivery step, open the [Commissioning] row, select [Edit notes], then [Save notes].

Note: To reverse a wrong selection, select [Undo] on the message at the bottom.
