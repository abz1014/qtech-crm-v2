1. Open the order. Once the job is due, the green button is [Mark done today].
2. Tap it when the job is finished. One tap.
3. No date yet? Admin and sales see the green button [Plan commissioning]: set the date and the engineers there.
4. Site notes: under [Commissioning], tap [Edit notes], then [Save notes].

Safe to try: tapped by mistake? Tap [Undo] on the message at the bottom.
