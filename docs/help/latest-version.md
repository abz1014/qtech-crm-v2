1. Open [Settings] from the menu under your picture. The version is at the bottom, for example "Version a1b2c3d · 26 Oct 2026".
2. Select [Check for update now].
3. It says "You have the latest version." or switches to the newest version automatically.

The app also updates automatically when it is reopened, unless typing is in progress. If [Reload] is shown, select it when ready. Entered text is kept.
