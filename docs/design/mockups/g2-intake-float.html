Memory card states

The same card under thin, old and imported data. Every rate is a count out of a count, and no card has a score.

Honesty rules in these frames

  • No percentage and no score anywhere. Rates read "answered 4 of 6".
  • "Usually replies in ~2 days" appears only with 3 or more logged replies.
  • Prices show the original currency first, then ≈ PKR at the captured rate, labelled "at the time".
  • Prices over 18 months old show their age before anything else.
  • Imported rows count towards the totals. A price with an unverified currency is hidden, and the footnote says how many.

Tier labels

  • same model: a shared model code, and the same brand when both are set.
  • same item: same brand and a similar description.
  • same brand: the supplier carries the brand.
  • same family: the item type only.
  • All four use one neutral style, so no tier looks like a better grade.

Order of suggestions

  • Supplied this item before, then carries the brand, then the family shortlist.
  • Ties go to the most recent contact.
  • Memory never re-orders the list.
  • Only the first group is pre-ticked.
