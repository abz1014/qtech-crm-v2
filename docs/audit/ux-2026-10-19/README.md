# UX audit, 2026-10-19

The owner asked for an audit of the UI and navigation after first using the live app ("the text size is very small").
Three read-only audits, run in parallel, against the code at `main` 2817623, the 117 mockup screenshots in `docs/design/screens/`
and the live login page:

- `navigation.md`: map of routes, tabs and dialogs; click paths for every core job per role; jargon, duplicates, dead ends; scores; 20 recommendations.
- `readability.md`: type scale and where each size is used, contrast from the tokens, density, phones; proposed larger scale and its costs.
- `screens.md`: per-screen counts and "5-second" and scan scores; the 10 highest-impact simplifications; what to keep.

Overall score 5.3/10 (mean of the 10 navigation and reading scores). The owner-facing summary and plan (steps 1 to 3) were
published as a private artifact. Owner decisions on text size, go-ahead and the 5-tab menu are recorded in DECISIONS.md when made.
